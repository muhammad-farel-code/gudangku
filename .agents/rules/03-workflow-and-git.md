# Workflow & Git

- Satu fase per sesi. Sebelum coding: tampilkan rencana file + perubahan.
- Setelah coding: jalankan `php artisan test` (jika sudah ada tes) dan
  `php artisan route:list` bila menyentuh route; laporkan hasilnya jujur.
  Jika ada error, perbaiki akar masalah, jangan menyembunyikan/skip test.
- Jangan membuat commit sendiri kecuali diminta. Sarankan pesan commit
  (conventional commits) di akhir tiap fase.
- Jelaskan keputusan desain penting dalam 3-5 kalimat agar pemilik bisa
  mengulanginya di video esai.
- Bila instruksi bertentangan dengan rules ini, STOP dan tanyakan.
- Jangan mengarang fakta (versi, nama package, perintah). Verifikasi dulu.
